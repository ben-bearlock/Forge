== Description ==

Forge is a lightweight, customizable WordPress theme for blogs, portfolios, business sites, and WooCommerce stores. It is a GPL fork of Astra 4.13.8 with header/footer builder slots unlocked and AI, analytics, and Upgrade-to-Pro UI removed.

Author: Ben Roos (TechJunkyBen)
Site: https://hire.techjunkyben.nl

== Installation ==

1. Copy this folder to wp-content/themes/ (you can rename the folder to forge).
2. Appearance → Themes → activate Forge.
3. Do not install official Astra or Astra Pro next to this theme.
